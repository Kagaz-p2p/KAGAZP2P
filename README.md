# KAGAZ
**Serverless peer-to-peer file transfer and chat, in a single HTML file.**

KAGAZ lets two devices send files and messages directly to each other, with no account, no sign-up and no server in the middle. The devices connect over WebRTC, so your files travel straight from one browser to the other and are never uploaded to the cloud.

## Highlights

- Send multiple files in both directions at the same time
- Live progress, speed and estimated time for every transfer, with cancel
- SHA-256 verification to confirm each file arrived intact
- Built-in chat that unlocks once the devices are connected, with a typing indicator
- Works offline on the same Wi-Fi or hotspot
- No backend, no build step, no dependencies: one HTML file
